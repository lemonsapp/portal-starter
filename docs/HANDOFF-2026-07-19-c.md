## 1. Qué estaba mal (y de dónde salió cada cosa)

| Archivo | Qué mostraba | Origen |
|---------|--------------|--------|
| `landing/public/icons/icon-192.png` + `icon-512.png` | **Globo terráqueo con hojas y avión sobre fondo amarillo** — logo de OTRA web de Lemons | `49ddd16` copió `client/public/icons` → `landing/public/icons` cuando el portal referenciaba `/icons/*` en raíz; en ese momento los PNG del client eran ese globo (492×524, ni cuadrados) |
| `landing/public/icons/icon.svg` | Limón sobre círculo navy (boilerplate Lemons) | mismo commit `49ddd16` |
| `landing/public/favicon.ico` + `favicon.svg` | Logo default de **Astro** (la "A" con espiral rosa) | scaffolding de Astro, nunca se reemplazó (`87dc9da`) |

Eso es lo que el cliente veía "de otra web": según superficie, el globo
amarillo (PWA/mobile), el limón, o la A de Astro (Google usa `/favicon.ico`).

## 2. Qué se hizo

Todo se regeneró desde el favicon **original de Holistic**:
`landing/public/imagenes-web/marca/favicon.svg` (H blanca itálica sobre
cuadrado negro redondeado — la misma H de `marca/logo.svg`, el logo H®).

- `landing/public/favicon.svg` ← copia de `marca/favicon.svg` (chau Astro).
- `landing/public/favicon.ico` ← H renderizada a 48×48 (PNG con extensión
  .ico, mismo formato que ya usaba el archivo viejo; Google recomienda ≥48px).
- `landing/public/icons/icon.svg` ← copia de `marca/favicon.svg` (chau limón).
- `landing/public/icons/icon-192.png` + `icon-512.png` ← regenerados con
  sharp desde el SVG (cuadrados de verdad, chau globo).
- `landing/public/icons/apple-touch-icon.png` ← **nuevo**, 180×180 para iOS.
- `BaseLayout.astro`: se agregaron `<link rel="icon" sizes="192x192">` (PNG
  fallback) y `<link rel="apple-touch-icon" sizes="180x180">` — antes solo
  había el link SVG, iOS no tenía apple-touch-icon.

El portal (`client/public/icons/*`) ya estaba bien desde `f9d8e41` (H en
icon.svg, 192 y 512 — verificado visualmente de nuevo hoy). No se tocó.

Build de Astro completo OK (10 páginas); el HTML generado sale con los
tres links de icono.

## 3. Superficies cubiertas

- **Web desktop**: rel=icon SVG (ya estaba) + PNG fallback + `/favicon.ico`
  real de Holistic (esto es lo que usa Google en resultados de búsqueda).

- **Mobile/Android-PWA**: `/icons/icon-192.png` y `icon-512.png` ahora H.
