## 2. Aprendizajes / trampas descubiertas

- **Patrón repetido**: tres reglas del wizard (`signup_mode`, `coins_on_register`,
  config de Resend) existían en `configStore`/UI pero el código las ignoraba con
  valores hardcodeados. Si algo "no responde al wizard", buscar el hardcode.
- **Desfase de deploys**: Vercel deploya en ~2 min, Render en ~7-8. Un cambio que
  toca contrato client↔server (ej. registro sin invite_code) da errores
  transitorios ("Datos inválidos") hasta que Render alcanza. Verificar con curl
  qué versión sirve la API antes de diagnosticar.
- **`.env` de la raíz del Codespace apunta a la DB VIEJA** (branding "Holistic
  Growshop", la de `portal-starter-api`), NO a producción. Sirve para dev/boot
  test. El test `configStore.test.js` ESCRIBE en esa DB (falló 1 assert porque
  asume DB vacía — pre-existente, no es regresión).

## 3. ⚠️ PENDIENTE CRÍTICO — pasos manuales para que llegue el mail

El código está arreglado pero el mail sólo va a llegar cuando el cliente haga:

1. **Resend → Domains → Add `hgrowshop.com`** → cargar los 3 records DNS que da
   (MX + 2 TXT) en **Cloudflare** (DNS only) → Verify.
2. **Wizard `/admin/setup` → sección Resend**: API key (`re_...`) +
   `from_email` = algo `@hgrowshop.com` (dominio verificado) + `from_name`.
3. Probar con "¿No te llegó? Reenviar mail" en la pantalla post-registro.

Al cierre de la sesión el cliente quedó en hacer 1 y 2.
