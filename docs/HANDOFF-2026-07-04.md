(Render) corre código viejo**. El frontend (Vercel) sí toma los cambios solo; el
server (Render) aparentemente **no tiene Auto-Deploy activo** o no redeployó.

**Acción pendiente del usuario (destraba casi todo):**

   Deploy → Deploy latest commit**.

- `POST /api/admin/shop/test-email` (test de Resend).

## Hecho esta sesión

**Shop (storefront) — atmósfera premium con GSAP** (catálogo, ficha, carrito,
checkout): aurora de luz, grano, spotlight de cursor, tilt 3D + spotlight en
cards, glitch de títulos, barridos de CTA. Todo respeta `prefers-reduced-motion`
y se aligera en mobile. Calibrado a intensidades sutiles.

**Fixes de compra:**
- Página de éxito no mostraba "completado": ahora **poll-ea** el estado (webhook
  de MP llega después del redirect). Muestra "Confirmando tu pago…".
- Compra con **cupón** no mostraba nada: era una race (clear() del carrito
  disparaba redirect a /shop). Sacado — la success page limpia el carrito sola.
- Ficha de producto quedaba cargando: **Rules of Hooks** (useGSAP estaba después
  de early returns) → movido antes.

**Mis pedidos** (`/mis-pedidos`, link en menú de usuario): panel de seguimiento
con timeline (Recibido → Pagado → En camino → Entregado), tracking y botón
**"SE RECIBIÓ"**. Server: `GET /api/shop/my-orders` (matchea por email de la
cuenta; el checkout es guest).

**Flujo de entrega:** admin despacha cargando carrier+tracking a mano (el botón
"Despachar" de la lista abre el detalle) → email al cliente con tracking (ya
existía) → cliente confirma con "SE RECIBIÓ" → si no, auto-entrega a los 2 días.

**Admin → Pedidos:** botones de estado **inline** por fila (Marcar pagado /
Despachar / Completar / Cancelar / Reabrir), + "Detalle".

**Avisos de nuevos pedidos:** solo staff. Guard en cliente (`AppNotification` no
muestra `type='order'` a no-admin) + refuerzo en `/notifications/active`.

**PWA / instalar app:** sacado el prompt "Instalar app" que salía solo. Nuevo
bloque `InstallHolistic` en el inicio: instala nativo (Chrome/Android/desktop) o
muestra instrucciones manuales (iOS "Agregar a inicio"). No se muestra si ya está
instalada.

**Admin claro estilo Tiendanube** (de sesiones/fases previas de HOY): design
system `.adm` (`client/src/pages/admin/ui.jsx`), publicador de productos
full-screen, shell claro, todas las pestañas migradas.

**Emails:** el código está correcto (Resend vía `sendResendEmail`). Si no andan,
es **config de Resend** (falta API key / dominio del remitente sin verificar).
Herramienta nueva: **Admin → Config → Ajustes → "Probar envío de email"**.
